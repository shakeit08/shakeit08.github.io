NEXT STAGE 소개 페이지 — 깃헙 페이지 올리는 법

1. (완료) 저장소: shakeit08/nextstage
2. 이 폴더 안의 index.html 과 assets 폴더를 통째로 업로드
   ※ 웹 업로드는 한 번에 파일 100개까지라 assets/emo(494장)가 걸림.
     GitHub Desktop으로 올리는 걸 추천. 웹으로 할 거면 emo 폴더를 100개씩 나눠 여러 번 업로드.
3. 저장소 Settings → Pages → Branch: main / (root) → Save
4. 1~2분 뒤 https://(아이디).github.io/nextstage/ 로 접속

수정할 것
- 다운로드 링크: index.html 에서 DOWNLOAD_URL = "https://LINK" 부분을 실제 링크로 교체
